## 📋 What You'll Deploy

- **Frontend:** Vercel (free, no credit card)
- **Backend:** Render (free, no credit card)
- **Database:** Supabase (free tier)
- **Storage:** Supabase Storage (free tier)

**Total Cost: $0/month**

---

## 🔑 Prerequisites

Before deploying, you need:
1. GitHub account
2. Groq API key ([get free](https://console.groq.com))
3. Supabase account ([sign up](https://supabase.com))
