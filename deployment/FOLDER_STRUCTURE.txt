⚠️  IMPORTANT: Environment Files

DO NOT commit .env files to Git!

Template files (safe to commit):
  ✓ samvada-backend/.env.backend
  ✓ samvada-frontend/.env.frontend

Your actual files (NEVER commit):
  ✗ samvada-backend/.env
  ✗ samvada-frontend/.env

To set up:
  cd samvada-backend
  cp .env.backend .env
  # Edit .env with your credentials

  cd ../samvada-frontend
  cp .env.frontend .env
  # Edit .env with your backend URL
