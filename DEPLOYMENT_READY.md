## 📁 What Changed

### Environment Files Renamed
- `samvada-backend/.env.backend` — Backend environment template
- `samvada-frontend/.env.frontend` — Frontend environment template

**To use:** Copy to `.env` and fill in your credentials:
```bash
cd samvada-backend
cp .env.backend .env
# Edit .env with your credentials

cd ../samvada-frontend
cp .env.frontend .env
# Edit .env with backend URL
```
